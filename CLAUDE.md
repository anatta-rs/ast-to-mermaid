# CLAUDE.md — ast-to-mermaid

Conventions for AI assistants working on this repo. Humans should also
read [CONTRIBUTING.md](./CONTRIBUTING.md).

## PR descriptions must include a blast-radius diagram

Every PR description must embed a Mermaid blast-radius diagram of the
change, generated by `a2m diff`:

```bash
a2m diff <base>..HEAD --format mermaid
```

Paste the output verbatim into a fenced ` ```mermaid ` block in the PR
body. GitHub renders Mermaid natively, so reviewers see added / modified
/ removed entities and the call edges between changed nodes at a glance.

Rationale: the diff is the tool's own output applied to itself — it is
the most precise way to communicate the surface of a change, and
keeping the convention forces us to keep `a2m diff` honest.
